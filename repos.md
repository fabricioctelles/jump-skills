## Formato

Cada seção segue o formato:

```
## [ninja-name]

Descrição opcional.

\`\`\`repos
https://github.com/org/repo1
https://github.com/org/repo2
\`\`\`
```

O script `sync-repos.sh` parseia os blocos `repos` de cada seção.
